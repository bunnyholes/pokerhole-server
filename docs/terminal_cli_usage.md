# 터미널 포커 CLI 데모 사용법

`PokerCliDemo` 클래스는 화살표 키와 엔터 입력으로 상호작용 가능한 포커 방 UI를 터미널에서 시연합니다.

## 실행 방법

```bash
gradlew -PmainClass=dev.xiyo.pokerhole.cli.PokerCliDemo run
```

또는 IDE에서 `PokerCliDemo` 클래스를 실행하세요.

## 조작법

- `←`, `→`: 하단 액션 슬롯을 이동합니다.
- `↑`, `↓`: 베팅/레이즈 금액을 증감합니다.
- `Enter`: 현재 선택된 액션을 확정하며 이벤트 로그에 기록합니다.
- `Esc`: 현재 선택을 취소하고 로그에 알립니다.
- `q` 또는 `Ctrl+C`: 데모를 종료합니다.

## 화면 구성

- 좌측 상단: 현재 판돈.
- 우측 상단: 시스템 시계.
- 중앙 상단, 좌중앙, 우중앙: 상대 플레이어 정보.
- 하단 중앙: 내 카드, 내 액션 배지.
- 좌측 하단: 보유 칩.
- 하단: 액션 선택 영역과 최근 이벤트 로그.

UI는 86×24 셀 캔버스를 사용하며 JLine 터미널을 통해 ANSI 시퀀스로 그려집니다.
